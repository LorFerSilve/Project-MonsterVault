## Current intent

The first production pass should not beautify the whole game.

It should make one representative Starter -> Capture -> Home/Vault -> Energy -> Showcase path feel like a real commercial Roblox game, while establishing reusable production standards for later rollout.

Halloween 2026 is implemented as a removable/configurable launch-season presentation layer over a permanent production-quality base.
