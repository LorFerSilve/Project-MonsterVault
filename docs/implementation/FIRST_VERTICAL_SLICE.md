# First Vertical Slice — VS-1

> **Locked by:** TA-17
> **Scope:** Trusted Join -> One World Creature -> Capture -> Secure Ownership -> Rejoin

The first implementation slice is intentionally narrow but crosses the highest-risk technical seams.

## Included

- DEV profile readiness/lease;
- V1 session/network handshake;
- one deterministic fixture World Creature;
- server interaction validation;
- capture state machine;
- server RNG / fixed Variant identity;
- Provisional Capture / Transport Custody;
- Secure Point finalization;
- one P2 Player Profile checkpoint;
- authoritative client projection;
- disconnect/rejoin reconciliation;
- baseline security/fault/accessibility/performance evidence.

## Excluded

- broad world content;
- passive production/economy beyond what is needed to represent the profile safely;
- social/events;
- trading;
- commerce;
- full live-ops/analytics;
- production publishing.
