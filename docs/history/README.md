`initial_foundation/` contains the first repository-level concept documents created before the StarForge-style GDS/TA governance model was introduced on 2026-09-15.

Those documents are valuable as design input and historical context, but their statements are **not automatically authoritative**. Each idea must be accepted, refined or rejected by its owning GDS phase before it becomes Design Complete.
