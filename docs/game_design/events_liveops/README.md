GDS-11 establishes shared wall-clock Event Occurrences, session-local Server Event Instances, prospective event Spawn Modifiers, contribution-gated exact-once rewards, dynamic Rifts/Event Zones, Event-Limited/Rotating Availability, explicit multi-award event capture using distinct personal Creature Instances, bounded Event Resolution Grace, server-hop anti-reroll rules and additive live-content rotation/hotfix semantics.

Ordinary event creatures remain single-award by default. Event-Limited content is never required for the baseline world progression graph, and GDS-11 authorizes no baseline event multiplier to Vault Passive Production.

The next dependency is **GDS-12 — Trading and Player Economy**.
