GDS-15 treats Roblox safety/policy eligibility as a live external dependency, keeps core progression independent of unrestricted chat/voice, avoids baseline public freeform user text, requires successful filtering for future user-visible text, preserves reporting/blocking access, keeps moderation non-confiscatory, targets a Minimal-to-Mild content envelope and avoids baseline paid-random or paid-item-trading complexity.
