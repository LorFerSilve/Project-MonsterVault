GDS-16 keeps retention subordinate to product health: no baseline login reward, login streak, absence punishment or mandatory daily checklist. Return Brief and Next Aspirations guide already-valid play without changing odds or fabricating rewards. Experiments require explicit hypotheses, primary metrics, guardrails, stable exposure and non-destructive rollback; ownership, safety, rarity integrity, trade atomicity and accessibility remain Experiment Invariants.
