GDS-13 authorizes deterministic cosmetics/status, bounded Collection/Display Capacity convenience, a durable supporter/style pass and one one-time deterministic Starter Value Bundle with only small bounded acceleration.

GDS-13 does not authorize unlimited paid Energy, production acceleration, paid luck/rerolls/capture power/claim priority, paid core world/event/trade access, randomized paid acquisition, recurring subscriptions or paid server-wide gameplay boosts.

The next dependency is **GDS-14 — Presentation, UI/UX, Feedback, and Accessibility**.
