GDS-10 preserves ordinary single-award capture and one-owner collection semantics while adding consent-based Parties, contribution-gated cooperation, bounded personal Collaboration Rewards, public pre-claim competition, non-destructive Friendly Challenges, read-only Vault socialization and non-obstructive multiplayer movement.

Direct-combat PvP, transport interception, wagering and involuntary player-caused persistent-value loss are not baseline mechanics.
